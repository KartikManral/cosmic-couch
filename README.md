# Cosmic Couch

A psychedelic chill hub in one tab: shader-based trance tunnels, six live-generated radio stations and a small catching game.

Every sound and visual is generated in the browser with Web Audio and WebGL. There are no media files.

## Run it

Open `index.html` in a browser. There's no build step and no dependencies.
